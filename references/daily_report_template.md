# Daily HTML Report Template

The daily report is a standalone HTML file grouped by game.

Required sections:

1. 日报总览
2. 样本范围与限制
3. 值得关注的事件
4. 按游戏分组舆情
5. 玩家倾向与情绪
6. 平台差异
7. 风险预警
8. 今日新增/升温/降温
9. 证据链接表
10. 待验证线索

Every item in core sections must cite an evidence ID and URL.

Use badges for:

- high / medium / low risk
- positive / negative / neutral / mixed sentiment
- source AI
- platform

For each game, show:

- overall player tendency
- top events
- platform distribution
- risk summary
- evidence links
- pending leads
